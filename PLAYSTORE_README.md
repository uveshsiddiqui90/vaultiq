# VaultIQ — Smart Personal Expense Tracker

## 🎯 App Description (for PlayStore)

**VaultIQ** is your intelligent personal finance companion. Track every rupee you spend, set monthly budgets, and build better financial habits—all with a sleek, intuitive interface.

### ✨ Key Features

🏠 **Smart Dashboard**
- Real-time budget overview at a glance
- Available balance calculated instantly
- Recent transactions displayed automatically

💰 **Budget Management**
- Set and adjust your monthly budget anytime
- Automatic month-end carry-forward (your budget carries to next month)
- Smart budget alerts (warning at 80% usage)
- Budget vs. spending progress bar

💸 **Expense Tracking**
- Quick expense entry with categories
- Add notes to remember purchase details
- Multiple payment methods supported
- Flexible date selection

📊 **Analytics & Insights**
- Visualize spending by category with charts
- Monthly spending trends
- Category-wise breakdown with percentages
- Compare spending across months
- Top spending category highlight

👤 **Profile & Security**
- Secure email/password authentication
- Profile customization with profile picture
- Change password anytime
- Quick logout option

🔐 **Data Security**
- End-to-end encrypted with Supabase
- Your financial data is private
- No data sharing with third parties
- GDPR compliant

### 💡 Why VaultIQ?

✅ **Free** — No subscription, no hidden fees
